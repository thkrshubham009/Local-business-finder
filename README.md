# OpportunityOS

OpportunityOS is an AI-powered platform that helps students discover opportunities, make informed career decisions, and build practical action plans for their future. Instead of generic advice, it generates personalized, realistic roadmaps based on each user's profile, interests, education, and goals.

The platform is designed to be honest rather than motivational. It identifies skill gaps, recommends scholarships, competitions, learning resources, projects, and provides structured guidance for students preparing for university and future careers.

## Features

- Personalized AI Roadmap Generator
- AI Career Navigator
- Opportunity Finder
- Scholarship Recommendations
- Competition & Olympiad Discovery
- Government Scheme Suggestions
- Skill Gap Analysis
- Project Recommendations
- Free Learning Resource Suggestions
- Clean and responsive interface
- Mobile-friendly design

## Running Locally

Clone the repository:

```bash
git clone https://github.com/yourusername/opportunityos.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.streamlit/secrets.toml` file:

```toml
GEMINI_API_KEY = "YOUR_API_KEY"
```

Run:

```bash
streamlit run app.py
```

## Vision

OpportunityOS aims to become a free platform where students from anywhere in the world can discover opportunities, explore careers, and receive realistic AI guidance regardless of their background or access to expensive counselling services.
